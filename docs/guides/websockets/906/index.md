# WebSocket — сборки 906, 1132 и 1333

Руководство подготовлено и проверено на WebSoft HCM Server `2023.2.906` с
Datex.XHTTP `1.24.4.27`. Те же основные примеры применимы к сборкам 1132 и 1333
с оговорками ниже.

## Применимость по сборкам

| Сборка WebSoft HCM Server | Datex.XHTTP | Статус |
| --- | --- | --- |
| `2023.2.906` | `1.24.4.27` | Примеры проверены на стенде |
| `2025.1.1132` | `1.25.2.20` | Добавлен массив команд; обработка ошибки отдельной команды имеет известное ограничение; стенд не проверен |
| `2025.1.1333` | `1.25.8.8` | Исправлена обработка ошибки в массиве команд; стенд не проверен |

В 1132 `main_socket` научился принимать массив команд и возвращать ответ на
каждую из них. Подробности и ограничение этой сборки описаны в
[главе о группах](groups.md#batch-commands). Одиночные команды, фильтрация
`GetWebSockets`, теги и отправка сообщений работают как в 906.

В 1333 исправлена обработка ошибки отдельной команды в массиве.

!!! warning "Проверка версий"
    Примеры выполнены только на стенде 906. Для 1132 и 1333 отдельно не
    проверялись ответы на массив команд и фактические коды закрытия.

## Порядок работы

1. [Подготовка и подключение](connection.md).
2. [Отправка сообщений](messages.md).
3. [Группы клиентов](groups.md).
4. [Работа с тегами](tags.md).
5. [Закрытие соединений](closing.md).

[Тестовый HTML-клиент](../ws-client.md) поддерживает служебную проверку связи
`$hbt` / `$ok` этих сборок.

Эти сборки используют теги соединений, фильтрацию `GetWebSockets` и параметры
`force_remote` и `no_remote`.

Примеры массовой отправки и закрытия соединений выполняйте только на изолированном тестовом стенде.
