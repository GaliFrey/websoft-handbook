# WebSocket — сборка 906

Руководство относится к WebSoft HCM Server `2023.2.906` и Datex.XHTTP `1.24.4.27`.

## Порядок работы

1. [Подготовка и подключение](connection.md).
2. [Отправка сообщений](messages.md).
3. [Группы клиентов](groups.md).
4. [Работа с тегами](tags.md).
5. [Закрытие соединений](closing.md).

[Тестовый HTML-клиент](../ws-client.md) поддерживает служебную проверку связи `$hbt` / `$ok` этой сборки.

Сборка 906 использует теги соединений, фильтрацию `GetWebSockets` и параметры `force_remote` и `no_remote`. Особенности последующих сборок будут отмечаться в разделе этой сборки рядом с затронутыми примерами.

Примеры массовой отправки и закрытия соединений выполняйте только на изолированном тестовом стенде.
