# WebSocket в WebTutor

Руководство разделено по поколениям WebSocket API. Сборка 434 несовместима с
более новыми версиями. Для сборок 906, 1132, 1333 и 1525 используется одно
руководство: основные примеры в них совпадают, а версионные особенности указаны
рядом с затронутыми действиями.

## Сборка 434

[Открыть руководство для WebSoft HCM Server 2022.1.3.434](434/index.md).

В этой версии используется Datex.XHTTP `1.22.6.9`: без тегов, фильтрации `GetWebSockets` и служебного heartbeat `$hbt` / `$ok`. Группы через `main_socket` хранятся в `tools_web`.

## Сборки 906, 1132, 1333 и 1525

[Открыть общее руководство для сборок 906, 1132, 1333 и 1525](906/index.md).

В этих сборках доступны теги, фильтрация `GetWebSockets` и heartbeat `$hbt` /
`$ok`. Полный набор примеров выполнен на сборке 906. Для последующих сборок
указаны найденные отличия; отдельно проверенные на стенде 1525 сценарии
перечислены ниже.

## Краткое сравнение

| Возможность | 434 | 906 | 1132 | 1333 | 1525 |
| --- | --- | --- | --- | --- | --- |
| Datex.XHTTP | `1.22.6.9` | `1.24.4.27` | `1.25.2.20` | `1.25.8.8` | `2.26.8.20` |
| Heartbeat `$hbt` / `$ok` | Нет | Есть | Есть | Есть | Есть |
| Теги WebSocket | Нет | Есть | Есть | Есть | Есть |
| `GetWebSockets` | Без параметров | Фильтр и `force_remote` | Как в 906 | Как в 906 | Как в 906; без `.ToArray()` |
| Группы через `main_socket` | Хранилище `tools_web` | Теги соединения | Теги соединения | Теги соединения | Теги соединения |
| Массив команд в одном сообщении | Нет | Нет | Есть, с дефектом обработки ошибок | Есть | Есть |

Поведение 1132 и 1333 на стенде не проверялось. На стенде 1525 проверены
подключение, heartbeat, обработка ошибочного JSON, перебор `GetWebSockets`,
команда `close_socket`, клиентское закрытие и `Abort()`.
