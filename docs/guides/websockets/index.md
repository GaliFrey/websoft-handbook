# WebSocket в WebTutor

Руководство разделено по сборкам сервера. Сначала выберите версию: примеры `main_ws_service`, API Datex.XHTTP и способы группировки несовместимы между сборками 434 и 906.

## Сборка 434

[Открыть руководство для WebSoft HCM Server 2022.1.3.434](434/index.md).

В этой версии используется Datex.XHTTP `1.22.6.9`: без тегов, фильтрации `GetWebSockets` и служебного heartbeat `$hbt` / `$ok`. Группы через `main_socket` хранятся в `tools_web`.

## Сборка 906

[Открыть руководство для WebSoft HCM Server 2023.2.906](906/index.md).

В этой версии используется Datex.XHTTP `1.24.4.27`: доступны теги, фильтрация `GetWebSockets` и heartbeat `$hbt` / `$ok`.

## Краткое сравнение

| Возможность | Сборка 434 | Сборка 906 |
| --- | --- | --- |
| Версия Datex.XHTTP | `1.22.6.9` | `1.24.4.27` |
| Heartbeat `$hbt` / `$ok` | Нет | Есть |
| Теги WebSocket | Нет | Есть |
| `GetWebSockets` | Без параметров | Фильтр и `force_remote` |
| Группы через `main_socket` | Хранилище `tools_web` | Теги соединения |
