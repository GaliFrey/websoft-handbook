# WebSocket — сборка 434

Руководство относится к WebSoft HCM Server `2022.1.3.434` и Datex.XHTTP `1.22.6.9`.

## Порядок работы

1. [Подготовка и подключение](connection.md).
2. [Отправка сообщений](messages.md).
3. [Группы клиентов](groups.md).
4. [Закрытие соединений](closing.md).

[Тестовый HTML-клиент](../ws-client.md) подходит для примеров, но проверку связи `$hbt` в этой сборке включать нельзя.

Сборка 434 использует `GetWebSockets()` без параметров и хранит подписчиков групп через `tools_web`. API тегов в этой версии отсутствует.
