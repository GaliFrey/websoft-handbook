# Преобразование XQuery в SQL

Раздел показывает, какой SQL формирует WebSoft для одного и того же XQuery в
разных сборках и СУБД. Опубликованные примеры остаются снимками конкретных
версий WebSoft HCM Server и SQL provider; для новых запросов и сборок
используйте инспектор.

## Статьи

- [WebSoft HCM 434 и MSSQL](./434-mssql/index.md)
- [WebSoft HCM 434 и PostgreSQL](./434-postgresql/index.md)
- [WebSoft HCM 906 и MSSQL](./906-mssql/index.md)
- [WebSoft HCM 906 и PostgreSQL](./906-postgresql/index.md)

Во всех статьях используются одинаковые XQuery. Это позволяет сравнивать
именно работу сборки и SQL provider, а не разные исходные запросы.

## Как получить SQL для нового запроса

Используйте проект
[websoft-xquery-inspector](https://github.com/GaliFrey/websoft-xquery-inspector).
Он обращается к активному UniBridge-провайдеру целевого экземпляра WebSoft HCM
и показывает:

- XQuery после серверной подготовки;
- основной SQL и Count SQL;
- параметры с типами и значениями;
- версии и служебные типы, необходимые для диагностики.

Установите DLL и настраиваемый шаблон по инструкции в README проекта, откройте
шаблон через маршрут своего портала, вставьте XQuery и запустите инспектирование
сочетанием `Ctrl+Enter`. Так можно проверить запрос непосредственно на нужной
сборке и СУБД без подготовки новой страницы этого раздела.

Инспектор не перечисляет результирующую коллекцию и не выполняет полученный SQL.
Сам транслятор UniBridge при подготовке может делать служебные запросы к схеме
базы данных. Результат зависит от версии
WebSoft HCM, SQL provider, схемы и настроек стенда, поэтому прикладывайте к SQL
диагностические данные инспектора. XQuery, параметры и SQL могут содержать
чувствительные данные: ограничьте доступ к шаблону администраторами и проверяйте
результат перед передачей третьим лицам.
