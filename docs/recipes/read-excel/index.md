# Как прочитать Excel-файл на сервере

Рецепт открывает файл `.xls` или `.xlsx` через `tools.open_excel()` и получает
строки первого листа как двумерный XML-массив.

## Условия применения

- Код выполняется на сервере.
- Метод `tools.open_excel()` присутствует в изученных поставках WebSoft HCM
  Server `2023.2.906` и `2025.1.1333`. В поставке `2022.1.3.434` метод не
  найден.
- Каталог с файлом должен быть разрешён параметром `DATA-DB` в `xhttp.ini`.
- Для изменения `DATA-DB` требуется перезапуск сервера.

## Подготовка

Поместите файл, например `import.xlsx`, в каталог сервера, доступный по URL
`x-local://1/import.xlsx`. Каталог `1` должен быть разрешён в `xhttp.ini`:

```ini
DATA-DB: 1
```

Не добавляйте в разрешённый список каталоги шире необходимого.

## Решение

```js
function getExcelCell(rows, rowIndex, columnIndex)
{
  try
  {
    return String(rows[rowIndex][columnIndex]);
  }
  catch (error)
  {
    return '';
  }
}

var fileUrl = 'x-local://1/import.xlsx';
var rows;

try
{
  rows = tools.open_excel(fileUrl).worksheet;
}
catch (error)
{
  throw 'Не удалось открыть Excel-файл "' + fileUrl + '": ' + error;
}

var rowIndex;
for (rowIndex = 0; rowIndex < ArrayCount(rows); rowIndex++)
{
  alert(
    'Строка ' + (rowIndex + 1) +
    ': A=' + getExcelCell(rows, rowIndex, 0) +
    '; B=' + getExcelCell(rows, rowIndex, 1)
  );
}
```

Индексы строк и столбцов начинаются с нуля. В прикладном импорте обычно нужно
пропустить строку заголовков и заменить `alert()` накоплением результата или
записью в журнал.

## Особенности структуры данных

В реализациях поставок `2023.2.906` и `2025.1.1333` наблюдается следующее:

- число столбцов определяется по непустым ячейкам первой строки;
- поддерживаются столбцы от `A` до `CZ`;
- чтение заканчивается на первой полностью пустой строке;
- значения ячеек приводятся к строкам.

Не оставляйте полностью пустые строки внутри таблицы и заполните заголовок у
последнего используемого столбца.

## Ограничения и безопасность

- Проверяйте расширение, размер и происхождение файла до обработки.
- Ошибки `Элемент не найден` и `Url host is not allowed` обычно означают
  неверный URL или отсутствие каталога в списке `DATA-DB`.
- Формулы, типы и форматирование не следует считать сохранёнными: рецепт
  работает со строковыми значениями ячеек.
- Структура с несколькими листами в рамках рецепта не проверялась.
