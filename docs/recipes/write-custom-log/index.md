# Как писать сообщения в отдельный журнал

Рецепт включает именованный журнал и записывает в него сообщения с
необязательным типом события.

## Условия применения

- Код выполняется на сервере.
- Используемая СУБД не имеет значения.
- Функции `EnableLog()` и `LogEvent()` подтверждены документацией Datex.
- Пример в таком виде на стенде WebSoft HCM не выполнялся.

## Решение

Включите журнал один раз до первой записи. Имя журнала передавайте в функцию,
а не фиксируйте внутри неё:

```js
function writeCustomLog(logName, message, messageType)
{
  var prefix = '';
  var messageText = '';

  if (messageType != undefined && messageType != null && messageType != '')
  {
    prefix = StrUpperCase(String(messageType)) + ':\t';
  }

  if (message != undefined && message != null)
  {
    messageText = String(message);
  }

  LogEvent(logName, prefix + messageText);
}

var logName = 'person_import';
EnableLog(logName, true);

writeCustomLog(logName, 'Импорт начат', 'info');
writeCustomLog(logName, 'Не заполнен код сотрудника', 'warning');
writeCustomLog(logName, 'Импорт завершён', 'info');
```

Ожидаемые строки:

```text
INFO:	Импорт начат
WARNING:	Не заполнен код сотрудника
INFO:	Импорт завершён
```

## Ограничения и безопасность

- Не включайте в сообщения пароли, токены, строки подключения и персональные
  данные без необходимости.
- Постоянно включённый подробный журнал расходует место на диске. Ротацию и
  очистку нужно настраивать отдельно средствами окружения.
- Этот помощник только форматирует строку. Категоризация, идентификаторы
  операций и обработка ошибок остаются ответственностью вызывающего кода.

## Источники и проверка

- [`EnableLog()`](http://docs.datex.ru/article.htm?id=5620250451197911774)
  — включает или выключает именованный журнал.
- [`LogEvent()`](http://docs.datex.ru/article.htm?id=5620276892448878667)
  — записывает строку в журнал указанного типа.
- Локально проверены структура Markdown и строгая сборка сайта. Выполнение на
  стенде WebSoft HCM не проводилось.
