# WebSoft Handbook

Новая версия личного практического справочника по WebSoft.
Стек: Markdown, Zensical, Python и uv. Старый сайт продолжает работать независимо.

## Запуск работы

Нужны Python 3.11+ и [uv](https://docs.astral.sh/uv/).
Все команды выполняются из корня этого проекта.

```bash
uv sync --locked
uv run --locked zensical build --strict
```

Версии зависимостей зафиксированы в `uv.lock`; его нужно хранить в Git вместе с исходниками.
Зависимости установлены, строгая сборка проверена. История проверок — в `history.md`.

Результат сборки — каталог `site/`, он не хранится в Git.

Предпросмотр запускается вручную, только когда он нужен:

```bash
uv run --locked zensical serve
```

## Структура

- `docs/index.md` — главная страница.
- `docs/recipes/` — короткие решения конкретных задач.
- `docs/explanations/` — разборы механизмов и подходов.
- `docs/guides/` — пошаговые руководства.
- `templates/recipe.md` — шаблон нового рецепта, не включается в сайт.
- `MIGRATION.md` — учёт переноса материалов.
- `zensical.toml` — оформление, навигация и Markdown-расширения.
- `history.md` — журнал завершённых изменений.

## Как добавить материал

1. Выберите формат: рецепт, разбор или руководство.
2. Создайте папку с коротким именем в kebab-case, например `docs/recipes/read-custom-field/`.
3. Создайте в ней `index.md`; для рецепта используйте `templates/recipe.md`.
4. Изображения размещайте рядом в `img/`, скачиваемые примеры — в `files/`. Пустые папки заранее не нужны.
5. Добавьте ссылку в каталог соответствующего раздела. Когда в разделе появится материал, замените текст об отсутствии публикаций списком ссылок.
6. Добавьте страницу в `nav` файла `zensical.toml`. Например, замените элемент рецептов на:

   ```toml
   { "Рецепты" = [
     "recipes/index.md",
     { "Чтение кастомного поля" = "recipes/read-custom-field/index.md" },
   ] },
   ```

7. Проверьте сборку, обновите `MIGRATION.md`, если это перенос, и добавьте запись в `history.md`.

Пути ссылок должны быть относительными, например `./img/result.png`.
Тексты, код и значения не следует оставлять только на скриншотах.
Указывайте версию платформы и условия проверки; отсутствие проверки не скрывайте.
Шаблоны и незавершённые черновики храните вне `docs/`: отсутствие страницы в меню не исключает её из публикации.

## Перенос и публикация

Источник — соседний проект `../websoft-guide/` и старые примеры из `../WebTutor-examples/`.
Оригиналы не изменяются. Материалы переносятся по одному с проверкой текста, кода и вложений.

Сначала проверяем новую схему на трёх материалах: коротком рецепте, инструкции с изображениями и большом разборе.
Окончательные пути статей определяются при переносе, а не заранее.

Публикация и GitHub Actions пока не настроены. `site_url` и `repo_url` намеренно не заданы.
Перед публикацией нужно выбрать адрес, задать его в конфигурации и решить вопрос старых URL и якорей.

Документация: [Zensical](https://zensical.org/docs/), [конфигурация](https://zensical.org/docs/setup/basics/).
